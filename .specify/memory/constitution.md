# NexusPatent Constitution

## Core Principles
1. **Zero-Knowledge Privacy by Default**: Technical embodiments and trade secrets never touch the public blockchain. Only cryptographic commitments (`claims_hash`) anchor on-chain.
2. **Dual-Engine Decentralized Verification**: Combines autonomous Web2 literature crawling (`gl.nondet.web.render`) with Multi-LLM Quorum consensus (`gl.vm.run_nondet_unsafe`).
3. **Economic Security & Collateralized Auditing**: Examiners must stake collateral to participate; fraudulent certifications result in slashing.
4. **Anti-Patent-Troll Invalidation Mechanism**: Stakeholders can challenge invalid or unoriginal claims with challenge bonds and counter-citations.
5. **Deterministic Composability**: Verified inventions can mint on-chain licensing certificates and fractionalized IP-NFTs.

## Governance & Invariants
- Minimum Examiner Bond: 5 GEN (`5 * 10^18 atto`).
- Minimum Challenge Bond: 3 GEN (`3 * 10^18 atto`).
- Patentability Threshold: Index >= 75 and Confidence >= 80%.
